To run the app:

`python3 -m http.server 8000`

Then hit http://127.0.0.1:8000/index.html to view the data or http://127.0.0.1:8000/data_admin_editor.html to add/edit the data.

The data can be found in the `data.json` file.

I tend to use AI to generate the data for me and add it manually rather than using the data editor.

Once happy, simply push the changes to Github where the pages will be built and served on https://spannerj.github.io/pafc_women/
